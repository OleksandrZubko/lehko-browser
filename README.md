# Легко — Browser Lab 0.3

Перший етап власного легкого браузера для Chrome на macOS. Він складається з двох частин:

- **Розширення Manifest V3.** Блокує рекламу й трекери засобами браузера (`declarativeNetRequest`), за бажанням прибирає AV1 на YouTube і звільняє пам'ять фонових вкладок.
- **Профіль `lean`.** Окремий профіль Chrome, де вбудовані механізми економії ввімкнені на максимум, а непотрібні служби вимкнені.

Власну збірку Chromium відкладено до перевірки виграшу.

## Легко.app

```sh
npm run app                                  # збирає artifacts/Легко.app
cp -R artifacts/Легко.app ~/Applications/
```

Це запускач для встановленого Chrome Stable. Він не завантажує й не збирає Chromium, тому Chrome і далі сам оновлюється, а Safe Browsing лишається ввімкненим. Профіль окремий: `~/Library/Application Support/Lehko/Profile`. Перед кожним запуском, поки профіль закритий, запускач застосовує налаштування lean і оновлює копію розширення в `…/Lehko/extension`. Під час першого запуску відкривається `chrome://extensions`: один раз увімкніть Developer mode, натисніть Load unpacked і виберіть цю папку.

## Профіль `lean`

```sh
npm run open:lean                               # Memory Saver «Максимальне», Energy Saver від батареї
npm run open:lab -- lean --energy-saver-always  # Energy Saver завжди: 30 fps, пропуски кадрів у 60 fps відео
npm run open:lab -- lean --no-energy-saver      # без Energy Saver
npm run open:lab -- lean --reader              # V8 без JIT: менше RAM, повільніший JS
npm run open:lab -- lean --freeze              # заморожування фонових вкладок, експериментально
```

Профіль лежить у `artifacts/profiles/lean`. Налаштування записуються перед запуском, тому профіль має бути закритий. Значення перевірено на Chrome 156 через `chrome.settingsPrivate`:

| Налаштування | Значення |
|---|---|
| `performance_tuning.high_efficiency_mode` | `state 1`, `aggressiveness 2`: Memory Saver «Максимальне» |
| `performance_tuning.battery_saver_mode.state` | `2`: Energy Saver від батареї. Варіант «завжди» (`3`) у тесті пропускав 12,5% кадрів 60 fps відео |
| `net.network_prediction_options` | `2`: без передзавантаження сторінок |
| `background_mode.enabled` | `false` |

Прапорці запуску:

- `--disable-features=SpareRendererForSitePerProcess,MediaRouter,OnDeviceModelBackgroundDownload,LensOverlay,Compose,OptimizationHints`
- `--enable-features=CompressParkableStrings,MemorySaverModeRenderTuning`: −3% пам'яті в довгій сесії без втрат у CPU
- `--autoplay-policy=document-user-activation-required`
- `--no-pings`

На порожньому профілі з однією сторінкою `lean` дав 9 процесів Chrome проти 11, renderer-процесів 2 проти 3: запасного renderer немає. Sandbox, site isolation, GPU, Safe Browsing та оновлення компонентів не змінюються.

`--freeze` вмикає `InfiniteTabsFreezing`. CPU фонових вкладок стабільно менший, а пам'яті в 6 прогонах із 7 було на 11% менше. В одному з 105 повернень вкладка не перемалювалась за 30 с, тому режим не ввімкнено за замовчуванням. Результати всіх механізмів Chromium описано в [docs/LONG_REPORT.md](docs/LONG_REPORT.md).

## Папки вкладок

У вікні відкриті лише вкладки поточної папки. Решта зберігається в `chrome.storage.local` як список адрес і не займає пам'яті. Секція «Папки» вгорі попапу або Alt+Shift+F:
- клік по папці — перемкнутися;
- ✎ — перейменувати;
- ↳ — перенести активну вкладку в папку;
- × — видалити папку;
- «+ Нова папка» — створити папку й перейти в неї.

При перемиканні активною стає вкладка, з якою ти працював востаннє, а решта відкриваються вивантаженими й завантажуються першим кліком. Закріплені вкладки не належать жодній папці.

На 16 сайтах, де 10 робочих вкладок лежать у неактивній папці, пам'ять становить 1241 MiB. Для порівняння: «Легко» з усіма відкритими вкладками — 2068 MiB, чистий Chrome — 3588 MiB. Повернення до робочої папки займає 2–3 с до повністю завантаженої вкладки. Деталі: [docs/FOLDERS_REPORT.md](docs/FOLDERS_REPORT.md).

Закрита вкладка втрачає введений у форми текст, історію «Назад» і `sessionStorage`. Тому перемикання спершу показує вкладки з відкритими DevTools, звуком або незбереженими формами, і ти вирішуєш: «Все одно перемкнути» або «Скасувати».

## QA і тестові сайти

- **Без блокування на тестових.** Увімкнено за замовчуванням. Діє на `localhost`, `127.0.0.1`, `*.test`, `*.local`, приватні IP (10.x, 172.16–31.x, 192.168.x, `[::1]`, `[fc00::/7]`) і позначені стейджинги разом із піддоменами. Сторінки цих сайтів та їхні фрейми завантажують усе, зокрема пікселі, аналітику й платіжні віджети, і такі вкладки не вивантажуються. Стейджинг позначається кнопкою «Позначити як тестовий».
- **Відкриті DevTools.** Поки DevTools відкриті, вкладка не вивантажується і не закривається при перемиканні папки. Про DevTools розширення дізнається через власну сторінку `devtools_page`, яка відкривається разом із ними.
- **Захист незбережених форм.** Вимкнено за замовчуванням, бо просить доступ до всіх сайтів. Перед вивантаженням або перемиканням папки «Легко» перевіряє поля вкладки й порівнює їх зі значеннями, з якими сторінку завантажено. Перевірка триває до 1,5 с на вкладку. Заздалегідь у сторінки нічого не вбудовується.

## Блокування й CPU

- **Реклама та трекери.** EasyList і EasyPrivacy перетворюються на статичні DNR-правила командою `npm run rules`: 3 824 і 9 121 правило, з доменами, згрупованими в `requestDomains`. Косметичні фільтри, `$popup`, `$document`, `$csp`, `$redirect` і regex не підтримуються. Список пропущеного друкує сама команда. Ліцензія списків: `extension/rules/LICENSE.txt`.
- **Пауза на сайті.** Кнопка «Вимкнути тут» додає динамічне правило `allowAllRequests` для поточного домену та його піддоменів.
- **Чужі вбудовані фрейми.** Суворий режим, вимкнений за замовчуванням. Не блокує капчі, Stripe, PayPal, Apple, Google і Microsoft login.
- **YouTube без AV1.** Вимкнено за замовчуванням і просить дозвіл лише для YouTube. Скрипт у світі сторінки повідомляє, що AV1 не підтримується, і плеєр бере апаратний VP9 або H.264. На 720p це −20…24% CPU renderer'а ([docs/AB_REPORT.md](docs/AB_REPORT.md)).
- **«Звільнити пам'ять зараз».** Вивантажує всі фонові вкладки, крім активних, закріплених, тих, що грають звук, що завантажуються, службових, з відкритими DevTools, тестових сайтів і, якщо захист форм увімкнено, з незбереженими формами. Кнопка вимагає другого натискання для підтвердження.
- **Набір «Розробка».** Позначені розширення вмикаються й вимикаються одним перемикачем; для цього потрібен дозвіл `management`.
- Лічильник на значку показує, скільки запитів заблоковано на вкладці.

## Встановлення

Готова папка розширення: [`dist/`](dist/). Архів: [`artifacts/lehko-0.3.0.zip`](artifacts/lehko-0.3.0.zip). Для збірки з вихідного коду потрібен Node.js 22+:

```sh
npm ci
npm run build
npm run open:lab
```

Остання команда відкриє Chrome з окремим профілем у `artifacts/profiles/extension`, не змінюючи основний профіль. У цьому вікні:

1. Відкрий `chrome://extensions`, увімкни **Developer mode**.
2. Натисни **Load unpacked** і вибери папку `dist` у цьому проєкті. Архів спочатку розпакуй.
3. Закріпи «Легко» на панелі розширень. На безпечному сайті відкрий його, підтвердь відсутність незбереженої роботи й натисни «Дозволити економію на цьому сайті».
4. Для експерименту вимкни штатний Memory Saver у `chrome://settings/performance`, щоб не змішувати політики. Перевір актуальний стан у самих налаштуваннях.

Chrome Stable більше не підтримує автоматичне встановлення через `--load-extension`. Ручне **Load unpacked** залишається способом локального встановлення; браузерний автотест використовує CDP лише в тимчасовому профілі. [Документація Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

## Автовивантаження вкладок

- Початково дозволених сайтів немає. Дозвіл стосується **точного hostname**: `example.com` не включає `www.example.com`. Сторінки одного hostname з різними портами/HTTP(S) мають спільний дозвіл.
- Перевірка раз на хвилину; таймер 15/30/60 хвилин. Chrome може відкласти alarm, зокрема під час сну комп’ютера.
- П’ять останніх використаних звичайних невивантажених вебвкладок захищені; перелік спільний для всіх вікон. Якщо таких вкладок не більше п’яти, вивантажень не буде.
- Активні вкладки **в усіх вікнах**, закріплені, зі звуком, ті, що завантажуються, службові сторінки та вкладки з `autoDiscardable: false` пропускаються.
- Вкладка залишається на панелі та перезавантажується при поверненні. Зміна дозволів, таймера або перемикача починає новий повний відлік неактивності.
- Налаштування зберігаються між запусками; таймери й лічильники починаються заново після перезапуску браузера. Звичайна зупинка MV3 service worker їх не скидає.
- Приватні вікна не підтримуються. Немає сервера й телеметрії. Content script є лише один, «без AV1», і він працює тільки на YouTube після вашого дозволу. Дозвіл `tabs` відкриває адреси/назви вкладок; вони показуються локально, у сховище пишуться дозволені домени й тимчасові числові дані активності.

**Не дозволяй автоматизацію для пошти, редакторів, дзвінків, передачі файлів або сайтів із незбереженою роботою.** Розширення не вміє надійно визначати всі ці стани. Відкликання дозволу зупиняє лише нашу політику: Chromium може самостійно звільняти пам’ять під системним тиском. У тестовому профілі не працюй з важливими чернетками.

«Вивантажень за сесію» рахує успішні дії розширення; «вивантажено зараз» показує всі поточні вивантажені вкладки, включно з діями браузера. Обсяг економії RAM в інтерфейсі не оцінюється.

## Будова

`src/policy.ts` — чиста політика; `src/controller.ts` — серіалізація подій і сховища; `src/worker.ts` — слухачі Chrome; `src/popup.ts` — інтерфейс. Тимчасовий стан у `storage.session` переживає зупинку worker. Події реєструються синхронно. Перед дією повторно читається вкладка; зміна активності/політики перериває поточний прохід.

`src/savings.ts` — блокування, пауза сайтів, AV1, ручне вивантаження й набір «Розробка»; `src/savings-popup.ts` — їхній інтерфейс; `scripts/lib/abp-to-dnr.mjs` — конвертер фільтрів; `scripts/lib/lean-profile.mjs` — налаштування профілю `lean`. `src/folders.ts` і `src/folders-popup.ts` — папки (прототип лишився в `folders/`); `src/protection.ts` — захист вкладок і тестові сайти; `src/devtools.ts` — сторінка DevTools, що повідомляє про інспектовану вкладку.

Дозволи: `tabs`, `storage`, `alarms`, `declarativeNetRequest`, `scripting`, `management`. Необов’язкові: YouTube (режим без AV1) і всі сайти (захист незбережених форм). Публічні API сайтів і розширень не змінюються. Для нативної v0.1 переносимо перевірену політику в Performance Manager Chromium, зберігаючи нативні перевірки безпеки вкладок, sandbox та ізоляцію сайтів.
