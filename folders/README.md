# Легко — Папки (прототип)

Папки вкладок у стилі Яндекс Браузера: у вікні відкриті лише вкладки **поточної** папки, решта зберігається в `chrome.storage.local` і не займає пам'ять.

## Запуск
`chrome://extensions` → «Режим розробника» → «Завантажити розпаковане» → папка `folders/`. Кнопка на панелі або `Alt+Shift+F` відкриває список папок.

## Як працює
- Перемикання: вкладки поточної папки знімаються в снапшот (url, назва, іконка, активна) і закриваються; вкладки цільової створюються наново. Завантажується лише раніше активна, решта одразу `tabs.discard` (лінива).
- Закріплені вкладки не належать жодній папці й ніколи не закриваються.
- Перше відкриття: папка «Основна» = поточні вкладки.
- Снапшот поточної папки оновлюється з debounce ~1 с після подій вкладок.
- У попапі: клік по рядку — перемкнутись; ✎ — перейменувати; ↳ — перемістити активну вкладку в папку; × — видалити (з підтвердженням; поточну не можна); «+ Нова папка» — створити й перейти.

## Тест
З кореня проєкту: `node folders/smoke.mjs` (реальний Chrome, тимчасовий профіль; `HEADED=1` — з вікном).

## Обмеження
- Працює з одним вікном: те, з якого відкрито попап; події інших вікон ігноруються.
- Chrome не зберігає url у вкладки, відкинутої до першої навігації, і змінює її id. Воркер тримає ці адреси в `storage.session` і виставляє при активації. Після перезапуску браузера цей кеш зникає: тоді адреса береться з останнього снапшоту папки (за індексом), а автоматичний снапшот ніколи не замінює реальні сторінки порожніми.
- Перший запуск у сесії браузера: якщо всі справжні сторінки у вікні належать збереженій поточній папці (відновлена сесія або порожня нова вкладка), папка відкривається заново зі сховища, а відновлені вкладки закриваються. Сторінки, яких у папці немає, не чіпаються й потрапляють у снапшот.
- Відкриття ледачої вкладки все одно ініціює початок запиту (`tabs.create` стартує навігацію до `discard`).
- URL, які `tabs.create` відхиляє, під час відновлення пропускаються.
- Режим інкогніто вимкнено.
